### [L4D2] hx_stats

**Сайт:** [forums.alliedmods.net](https://forums.alliedmods.net/showthread.php?t=298535) 

### Основные функции плагина (RU)

* Предназначен для режима Coop в L4D2.
* Подсчитывает очки (Points) игроков.
* Фиксирует время последнего посещения сервера.
* Подсчитывает общее время, проведенное в игре (в минутах).
* Включает в себя веб-интерфейс для отображения статистики игроков.
* Изменяет цвет модели игрока в зависимости от количества набранных очков.
* Подсчитывает количество убитых зараженных: Boomer, Charger, Hunter, Common Infected, Jockey, Smoker, Spitter, Tank, Witch.
* Команда !rank (sm_rank в консоли) — отображение личной статистики игрока.
* Команда !top (sm_top в консоли) — вывод списка из 15 лучших игроков.
* Блокирует команду callvote для игроков, имеющих менее 500 очков.
* Блокирует команду go_away_from_keyboard для игроков, имеющих менее 50 очков.

### Main Plugin Functions (EN)

* Designed specifically for L4D2 Co-op mode.
* Tracks player Points.
* Records the timestamp of the player's last visit.
* Tracks total time spent in-game (in minutes).
* Includes a web interface for displaying player statistics.
* Changes player model color based on their current Points.
* Tracks kill counts for: Boomer, Charger, Hunter, Common Infected, Jockey, Smoker, Spitter, Tank, and Witch.
* !rank command (sm_rank in console) — displays the player's personal statistics.
* !top command (sm_top in console) — displays the top 15 players list.
* Blocks the callvote command for players with fewer than 500 points.
* Blocks the go_away_from_keyboard command for players with fewer than 50 points.
